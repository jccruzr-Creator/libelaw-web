# LIBELAW · Landing jurídica

Landing estática para presentar a Dayana Lucía Mechán Alvarez, explorar servicios y coordinar consultas virtuales. HTML, CSS y JavaScript sin compilación ni dependencias externas.

Web: https://jccruzr-creator.github.io/libelaw-web/

## Abrir y editar

Servir esta carpeta con un servidor HTTP estático y abrir index.html. Ejemplo: `python -m http.server 4183`. Editar contactos públicos en config.js; no introducir credenciales.

| Archivo | Función |
|---|---|
| index.html | Contenido, servicios y formulario. |
| styles.css | Diseño base y adaptación móvil. |
| experience.css / experience.js | Refinamiento visual, filtros y movimiento. |
| app.js | Menú, privacidad y solicitud de cita. |
| config.js | WhatsApp y zona horaria. |
| dayana.jpg | Retrato suministrado por la marca. |
| isotipo.png / logo-original.png | Isotipo real y logo completo, sin redibujar. |
| DESIGN.md | Fuentes, colores, animación y decisiones. |
| REVISION_2026-10-20.md | Verificaciones y límites. |

## Contacto y agenda

Cada tarjeta preselecciona el servicio. El visitante completa nombre y horario de Perú y revisa el mensaje en WhatsApp antes de enviarlo. No se guardan datos ni se confirma automáticamente una cita. Google Calendar es una alternativa externa gestionada por MENTEC y su titular se explica junto al enlace.

## Publicación

GitHub Pages sirve el repositorio público jccruzr-Creator/libelaw-web. Revisar los cambios de la rama antes de integrarlos en main y comprobar el despliegue. El historial permite recuperar la versión anterior.

## Criterios de edición

Mantener etiquetas, foco visible, navegación por teclado, proporciones del logo y compatibilidad con movimiento reducido. No añadir precios, ahorros, testimonios, credenciales ni resultados sin confirmación de LIBELAW. La revisión visual y funcional no equivale a una auditoría jurídica ni a una certificación de accesibilidad.
